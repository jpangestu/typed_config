## 0.1.0

- Initial release of Riverpod integration for `typed_config`.
- `ConfigNotifier` for fine-grained per-entry reactivity and synchronized background persistence.
- `configProvider` for supplying the root `Config` instance into `ProviderScope`.
- `configEntryProvider` and `configEntryProviderFromEntry` helper factories.
- Re-exports `typed_config` for unified imports.
